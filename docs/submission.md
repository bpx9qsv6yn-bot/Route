# Submission paragraph

Finding a resource is only the first step. FairRoute builds on Florida Community Innovation’s existing Resource Map to help residents who walk, roll or use transit—and the caseworkers supporting them—understand whether they can realistically reach and use a service. It combines FCI listings with official transit data, personal travel limits and transparent accessibility evidence. Unknown entrances and boarding conditions stay visible, with practical questions to confirm before leaving. A citywide view reveals how access changes with mobility constraints, while a planning model makes the tradeoff between average access and the least-served location explicit. The desktop prototype is runnable, tested and documented for handoff, with an optional Gemini tool-calling interface for plain-language assistance.

# Showcase status

The revised showcase uses four continuous recordings of the working app: real search and route computation, the entrance-requirement reversal, the mobility-profile reveal, and investment comparisons. It preserves interaction timing within each take, with editorial cuts, close-ups, click indicators and narration. The pantry example is explicitly fictional; citywide and planning figures come from the deterministic model. Gemini is implemented but not shown as a successful live interaction because only a dummy key was supplied.
